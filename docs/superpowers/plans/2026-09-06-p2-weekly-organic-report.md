# P2 Weekly Organic Report Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship one transport-free Weekly Organic Report workflow in `yandex-seo` that consumes normalized Webmaster/Metrika evidence and emits deterministic JSON, self-contained HTML, optional Mermaid/DOT diagrams, and a hashed artifact manifest.

**Architecture:** Keep all executable P2 runtime plugin-local under `plugins/yandex-seo/scripts/`. `seo_weekly_model.py` owns schema normalization and deterministic findings; `seo_weekly_artifacts.py` owns canonical JSON, IDs, path safety, immutable artifact sets and manifest hashing; `seo_weekly_html.py` renders self-contained escaped HTML; `seo_weekly_graphs.py` renders source-backed graph exports; `seo_weekly_report.py` is the thin CLI/orchestrator. Service transport remains owned by Webmaster/Metrika and is never imported into SEO.

**Tech Stack:** Python 3.10+ standard library only; `unittest`; JSON; self-contained HTML/CSS/minimal JS; Mermaid text; Graphviz DOT text; existing repository validator/CI/release publisher.

**Spec:** `docs/superpowers/specs/2026-09-06-p2-weekly-organic-report-design.md`

## Global Constraints

- Public report schema is exactly `seo-weekly-organic-report/v1`.
- Artifact manifest schema is exactly `yandex-ai-artifact-manifest/v1`.
- `yandex-seo` remains transport-free and credential-free; no service HTTP/client imports.
- Claim classes remain `OBSERVED|DERIVED|HYPOTHESIS|METHODOLOGY`.
- P1 memory is optional read-only context; it never replaces fresh source evidence or grants P0 write authority.
- `report.json` is normative; HTML/graphs may not add conclusions absent from source JSON/artifacts.
- HTML is self-contained: no CDN, remote fonts, analytics, network fetch, frames or external media.
- Artifact directories are immutable snapshots. Same `report_id` with different generated bytes fails closed; exact deterministic replay is allowed only when managed hashes match.
- No third-party Python dependencies.
- Planned release set: Repository `1.3.0` + Yandex SEO `1.2.0`; all other plugin versions/tags unchanged.
